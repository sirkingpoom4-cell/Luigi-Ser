# Android Car Web

หน้าจอสไตล์ Android Auto สำหรับเปิดในเบราว์เซอร์ของ Tesla (จอแนวนอน ธีมมืด ปุ่มใหญ่)

เปิดใช้งาน: https://sirkingpoom4-cell.github.io/Luigi-Ser/

- **นำทาง:** ค้นหาสถานที่ (OpenStreetMap Nominatim), คำนวณเส้นทาง (OSRM), บอกทางทีละจุดพร้อมเสียงภาษาไทย, คำนวณเส้นทางใหม่เมื่อออกนอกเส้นทาง, ปุ่มส่งต่อไป Google Maps / Waze
- **แผนที่:** CARTO dark tiles (สำรองด้วย OpenStreetMap), ตำแหน่งและความเร็วจาก GPS
- **เพลง:** เล่นไฟล์เพลงจากเครื่อง/USB พร้อมปกอัลบั้มและชื่อศิลปินจากไฟล์
- **แอป:** ทางลัด 18 แอปพร้อมโลโก้ (Simple Icons) เพิ่ม/ลบเองได้
- **อื่น ๆ:** นาฬิกา, สภาพอากาศ (Open-Meteo), ตั้งค่าสี/ขนาดตัวอักษร/เสียง

ไฟล์เดียว `index.html` ไม่ต้อง build มี Leaflet 1.9.4 และ jsmediatags ฝังอยู่ในไฟล์
