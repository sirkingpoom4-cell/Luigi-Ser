# Android Car Web

หน้าจอสไตล์ Android Auto สำหรับเปิดในเบราว์เซอร์ของ Tesla (จอแนวนอน ธีมมืด ปุ่มใหญ่)

- `index.html` คือไฟล์เดียวที่ต้องใช้ เปิดผ่านเว็บโฮสต์ใดก็ได้ (GitHub Pages, Netlify)
- `app.html` คือเนื้อหาเดียวกันสำหรับหน้าตัวอย่างใน claude.ai

ฟีเจอร์: แผนที่ (OpenStreetMap/CARTO), ความเร็วจาก GPS, สภาพอากาศ (Open-Meteo), เล่นไฟล์เพลง, ทางลัดแอปที่แก้ไขได้, ตั้งค่านาฬิกา/สี/ขนาดตัวอักษร
